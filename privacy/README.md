
# Privacy Policy – Roleplay Manager

**Last updated: October 31, 2026**

## 1. General Information

Roleplay Manager is a Discord bot developed under the project name ArthurDev. This Privacy Policy explains what information may be processed when using the bot.

## 2. Information Processing

To provide its functionality, Roleplay Manager may temporarily process information supplied by Discord, including:

- Discord user IDs
- Discord server IDs
- Channel IDs
- Role IDs
- Command inputs and interaction data

This information may be required to execute commands and provide the requested functionality.

## 3. Data Storage

According to the current implementation, Roleplay Manager does not maintain its own database, JSON-based user profiles, or other permanent user-data storage.

The bot does not intentionally create logs containing Discord user IDs, usernames, or server information. Only technical errors are logged.

Depending on the error, technical information may nevertheless appear in error logs.

## 4. Hosting Provider

Roleplay Manager is hosted by KataBump.

The hosting provider may process technical information required to operate the service, including application files, configuration data, and technical logs.

For further information, please consult the [KataBump Privacy Policy](https://legal.katabump.com/en/privacy/).

## 5. Discord

Roleplay Manager uses Discord's API to provide its functionality.

Information provided through Discord interactions may be processed by the bot. Discord's own data processing is subject to its [Privacy Policy](https://discord.com/privacy).

## 6. Purpose of Processing

Information is processed only to the extent necessary to:

- Execute bot commands.
- Provide server-management features.
- Process Discord interactions.
- Identify and resolve technical errors.
- Maintain the operation and security of the bot.

## 7. Data Sharing

Roleplay Manager does not sell personal information or share it for advertising purposes.

Technical processing by Discord and KataBump may occur as part of providing the service.
